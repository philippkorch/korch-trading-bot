# KORCH AMD+FVG: сигналы GER40 в Telegram

Индикатор работает на твоём аккаунте TradingView и сам отправляет сигналы в Telegram через webhook. Сервер, Railway и yfinance для этого не нужны.

```
TradingView (график GER40 5M + индикатор)
        │  алерт по закрытию 5M-бара
        ▼
https://api.telegram.org/bot<ТОКЕН>/sendMessage
        │
        ▼
Твой Telegram
```

## Какие правила из Notion зашиты в индикатор

| Правило (Notion) | Как реализовано |
|---|---|
| Только по тренду: дневка вверх, часовик с восходящим моментумом | D1: закрытие выше EMA20, EMA20 растёт. H1: то же самое. Шорт зеркально. Если ни одно не выполняется, это боковик и сигналов нет |
| Снятие ликвидности в тайминг | В окне Frankfurt 09:00–11:00 или London 10:00–13:00 снят один из уровней: PDL/PDH, low/high ночного диапазона или 5M swing |
| Снятие внутри имбаланса 1H/4H | Проверяется FVG на HTF (1H по умолчанию, можно поставить 4H). В сигнале строка «Снятие в HTF FVG: да/нет». Опция делает это условие обязательным |
| Модели входа 5M: инверсия / BOS / поглощение | Все три, каждую можно отключить |
| Не выше структурного максимума | Лонг не даётся, если цена входа выше последнего swing high на HTF |
| Skip: основное движение дня ушло | Пропуск, если диапазон дня уже больше 80% ATR(14) D1 |
| Skip: за стопом неснятая ликвидность | Сигнал приходит с предупреждением ⚠️ |
| RR 2, риск 1% | Тейк = вход + 2 × стоп. В сигнале указано, сколько денег на пункт при риске 1% от депозита |
| Skip: красные новости, непонятный контекст | Индикатор этого не видит. В каждом сигнале есть напоминание проверить вручную |

Сигналов не больше одного в каждую сторону за торговое окно 09:00–13:00.

## Настройка (примерно 15 минут)

### 1. Новый токен бота
Старый токен лежит в публичном репозитории, поэтому его надо отозвать:
1. Telegram → @BotFather → `/mybots` → твой бот → **API Token** → **Revoke current token**.
2. Сохрани новый токен у себя. Никуда его не вставляй, кроме поля URL в шаге 4.

### 2. Узнать свой chat id
Напиши боту @userinfobot, он ответит числом `Id`. Это твой chat id.
Потом обязательно нажми **Start** у своего торгового бота, иначе он не сможет тебе писать.

> В старых файлах `TELEGRAM_CHAT_ID` был равен id самого бота (`8999356089`). Бот не может писать сам себе, поэтому сообщения не приходили.

### 3. Добавить индикатор
1. TradingView → открыть GER40 (например `PEPPERSTONE:GER40` или `CAPITALCOM:DE40`, бери символ своего брокера) → таймфрейм **5m**.
2. Внизу **Pine Editor** → вставить код из `korch_amd_fvg.pine` → **Save** → **Add to chart**.
3. Настройки индикатора:
   - **Часовой пояс таймингов**: зона, в которой записаны времена в Notion (по умолчанию `Asia/Jerusalem`).
   - **Chat ID**: число из шага 2.
   - **Депозит** и **Риск %**: для расчёта суммы на пункт.

### 4. Создать алерт
1. Alerts (⏰) → **Create alert**.
2. Condition: **KORCH AMD+FVG** → **Any alert() function call**.
3. Expiration: **Open-ended**, если тариф позволяет.
4. Notifications → **Webhook URL**:
   ```
   https://api.telegram.org/botYOUR_NEW_TOKEN/sendMessage
   ```
5. Поле Message не трогай, текст сообщения формирует индикатор.
6. **Create**.

Webhook есть только на платных тарифах TradingView, и для него нужна включённая двухфакторная аутентификация (2FA).

### 5. Проверка
Самая быстрая проверка, что токен и chat id правильные: открой в браузере
`https://api.telegram.org/botYOUR_NEW_TOKEN/sendMessage?chat_id=YOUR_CHAT_ID&text=test`
Если в Telegram пришло «test», связка работает.

## Какие сообщения приходят

- ⚠️ **Снятие ликвидности**: тренд совпадает, ликвидность снята в тайминг, ждём модель входа.
- 🟢/🔴 **Сигнал**: вход, стоп, тейк, сколько пунктов, сумма на пункт, FVG, структурный уровень, предупреждения.
- ⏸ **Пропуск** (по умолчанию выключено): сетап был, но не прошёл фильтр. Причина указана.

## Ограничения

- Это механическая версия твоих правил. «Контекст непонятен» и «зоны против меня на HTF» индикатор не оценивает, это решение за тобой.
- Тренд определяется через EMA. В Notion он описан словами, поэтому формализация моя, и её стоит проверить на истории.
- Перед реальной торговлей прогони индикатор на истории (Replay) и сравни с журналом Backtest 300.
